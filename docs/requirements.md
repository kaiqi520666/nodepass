# 需求与约定

更新：2026-11-11。保留用户已确认的决定；实现入口见 [Agent 入口](README.md)，关键计费和恢复规则见[任务与账务](task-lifecycle.md)。

## 产品与权限

- 图片、视频生成与文本多模态 API 中转；官网、用户和管理员共用前端工程、登录与主题。
- 官网：首页、模型广场、API 文档、客服、注册登录；登录后点击账号名进入控制台，仍可浏览公开页面。
- 控制台五项：仪表盘、模型定价、API 令牌、任务日志、账户设置；管理员继承全部用户能力，另有用户管理、供应商配置、模型与价格、系统设置。
- 后端校验管理员身份及账户数据归属，不能用菜单隐藏或 UUID 难猜代替权限。同一账户不同有效 Key 可查询该账户任务；他人任务返回 404。
- 邮箱加密码注册；不自动把首个用户设为管理员，显式初始化见[根目录 README](../README.md#管理员)。
- 不做网页创作台、多线路、自动切换、在线支付、邮箱验证、找回密码、自动清理或业务次数/频率/并发配额；保留输入、上游能力及资金校验。

## 协议边界

- 对外提供约定范围内的 OpenAI 兼容能力，不承诺完整协议或所有 SDK 功能可用；开发者必须使用本站 API Key Bearer 鉴权，不能用网页 Cookie 代替。
- 已实现：`GET /v1/models`、`POST /v1/chat/completions`、`POST /v1/responses`、图片创建/查询、视频创建/查询。
- 图片生成 `POST /v1/images/generations`、编辑 `POST /v1/images/edits` 共用 `GET /v1/images/generations/{task_id}` 查询；视频为 `POST /v1/videos` + `GET /v1/videos/{task_id}`。均为本站异步扩展；创建返回 202，成功结果返回 URL。
- `/api/public/models` 只供网站目录使用，不作为开发者契约或调用示例；账户及管理接口不进入公开 OpenAPI。
- 图片一次一张，`n` 只允许 1。`tier/series` 是本站扩展，`size` 是比例；生成的 `response_format` 当前虽接受 `b64_json`，实际仍只返回 URL，不提供 Base64 输出示例。编辑的该字段可省略，显式传入只接受 `url`。
- 图片编辑仅接收 JSON：`images: [{image_url: HTTPS_URL}]` 为有序非空数组，`mask: {image_url: HTTPS_URL}` 可选，作用于首图；不接收 multipart、文件 ID 或 data URI。参考图数量不额外计价，沿用模型精确价目；参考图及 mask 在冻结前校验。
- 文本模型为 `gpt-6.1-sol`，支持显式消息历史、JSON/SSE、图片理解与严格 JSON Schema，不支持音频/视频理解。两种接口支持自定义函数声明、调用和结果回传，由客户端执行函数；支持按请求开启联网搜索（JSON/SSE），不与自定义函数混用。Responses 返回搜索引用事件，Chat Completions 的 `delta.annotations` 为本站扩展。不支持 Responses 服务端会话或回答缓存。
- 文本媒体支持 HTTPS 和合法 Base64 data URI，媒体仅放用户消息；不能套用视频生成只收 HTTPS 的规则。
- HTTP 非 2xx 请求错误、HTTP 200 的生成任务失败、文本 SSE 流内错误分开说明；HTTP 200 不等于生成成功。错误码及字段出现条件按实际实现维护。
- 公开文档只示范已实现能力，使用占位符，不公开供应商、上游任务 ID、成本、OSS 配置或内部账户接口；具体模型规格链接模型广场。

## 用户、配置与数据

- API Key 支持名称、可选过期时间、查看/复制、编辑和删除。摘要认证，原文 Fernet 加密且非空，仅创建及当前用户主动查看/复制时返回；列表和日志不含完整 Key 或摘要。删 Key 不删历史任务和流水。
- 管理员通过一个操作菜单调整积分或修改密码；调账要求金额与备注并记流水，扣除不得超过可用余额。
- 一个本站唯一模型 ID 只绑定一个供应商和上游 ID；适配器负责协议差异。模型、能力、默认参数、价格和启停由后台维护，不做任意协议或公式引擎。
- 图片仅保留 `gpt-image-2`、`gpt-image-2.5`，用参数控制档位/分支，不再拆重复模型；不保留 2.6、旧别名或自动替换。
- 图片编辑参考数量和 mask 能力按数据库配置，不增加全站 16 张限制；不支持或超限返回 422。
- 视频分辨率、比例、时长、参考素材数量、首尾帧能力按型号配置；当前每型号只有无计价维度的默认价。可选分辨率/比例省略用默认值，显式不匹配返回 422。
- 成本与售价独立保存，不保存币种、不换汇；初始化同额不代表以后相同，不用公开报价自动覆盖后台配置。
- 1 元人民币 = 1 积分；余额、单价、成本和扣款统一八位小数，`Decimal` + `ROUND_HALF_UP`，不为旧开发数据新增兼容代码。
- 已确认素材最终支持上传与外链；当前图片编辑和视频生成只接受有序 HTTPS 参考素材，不强制转存外部参考素材。视频首尾帧计入参考图数量，图片编辑的 mask 单独校验。
- 生成结果统一转存阿里云 OSS，以配置的独立域名公开 URL 交付。素材、结果、任务及文本记录暂保留，用户不能删除调用记录，不做 24 小时清理。
- 文本只存用量、状态、计价快照和金额，不保存提示词或回答全文；个人响应不得泄露成本、供应商或完整内部快照。

## 界面约定

- 使用 Element Plus 和 `@element-plus/icons-vue`；设计任务按需读取[本地 UI/UX 技能](../.agents/skills/ui-ux-pro-max/SKILL.md)，不复制技能说明或引入其示例框架。
- 主题为明亮、暗黑、跟随系统，默认跟随系统，本机保存；复用现有主题逻辑和 CSS 变量，不建账户偏好表。
- 官网顶部导航和页脚，首页媒体暂用固定比例占位；控制台侧栏布局，无页脚、面包屑、顶部重复品牌文字，内容铺满，桌面/手机保留左右边距。
- 官网登录后显示账号名；控制台顶部不显示账号名，“返回官网”和管理员“用户管理”使用带图标按钮，退出独立；不增加仪表盘底部快捷链接。
- 客服与主题相邻，二维码用 Popover；公告铃铛仅控制台显示，用时间线弹窗。当前二维码占位、公告为空，不另建客服页面。
- 标题复用 `PageHeader.vue`，统一左侧色标；表格和分页用 `AppTable.vue`、`AppPagination.vue`。表格保留单层外框、横向分隔、8px 圆角，不启用单元格 `border` 或竖线。
- 分页在整个表格/卡片网格下方，默认 20 条，可选 50/100；本地先筛选后分页。图标按钮有可访问名称和必要提示，长 ID 可复制，不用省略号遮住主要操作。
- 模型目录用自适应多列卡片，不逐卡重复“图片/视频”；同价同单位的参数合并，保留实际 quality 名称，不另造“常规/高质量”。详情比例下依次为参考图、视频、音频上限、首帧、尾帧。
- `/api-docs` 桌面两栏目录、窄屏单折叠目录，各章 hash 深链。顺序：快速开始、鉴权、模型列表、文本对话、图片生成、图片编辑、查询图片任务、视频生成、查询视频任务、状态与错误。
- 文本对话章内标签切换 Chat Completions/Responses，默认前者，保留 `#chat-completions`、`#responses`；代码块可复制，不加文档框架或高亮库。
- 仪表盘四卡依次为可用积分、已用积分、请求次数、今日消耗，响应式四/两/一列；不显示“1 元 = 1 积分”。账户设置采用信息卡片，展示可用及冻结积分。
- Key 页按名称、密钥、状态、创建时间、过期时间、操作展示；查看/复制分开图标按钮，创建用弹窗，不重复“API Key”小标题。
- 管理表单用控件维护能力和紧凑价目，不要求编辑 JSON；凭证不回填，留空保留原值，金额用八位小数字符串；不显示币种字段或符号。
- 日志分“生成任务/文本调用”，支持 ID、模型、状态、日期筛选，生成额外筛图片/视频；生成当前本地分页，文本服务端分页。
- 生成日志为任务 ID/时间、类型、模型、状态、耗时、扣除积分、操作；不在任务信息重复模型名。ID 带复制，类型和账务用中文彩色 Tag，扣款与 Tag 整体居中，操作靠右。
- 查看/下载用图标，详情用按钮；无结果不显示“暂无结果”。图片用 ImageViewer，视频用原生播放器弹窗，不引第三方播放器。
- 文本日志显示输入/输出 token、耗时、扣款；未知金额显示“—”，真实零金额显示八位零。详情排版展示用量和销售快照，不展示消息正文或成本。
- 所有页面、弹窗适配三态主题、窄屏和键盘；状态不只靠颜色区分，不让文本或控件溢出重叠。
