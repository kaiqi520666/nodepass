# 需求确认

整理日期：2026-11-06。最近更新：2026-11-08。范围为第一版；图片生成受理、沧元异步 Worker、积分冻结、结果转存、结算/释放和 OSS 配置已实现，充值、视频和素材输入仍未实现，当前范围见[根目录说明](../README.md)。

## 已确认需求

### 产品定位

建设面向开发者和第三方应用的图片、视频 API 中转平台，上游使用第三方中转站。

- 对外接口遵循已支持范围内的 OpenAI 兼容协议。
- 对外公开模型目录、对应价格和 API 文档，无需注册或登录即可阅读。
- 不提供网页创作台，不制作网页提示词生成、作品编辑等创作功能。
- 用户控制台承载账号、API Key、积分、任务日志和调用管理；任务日志支持按任务 ID、类型、状态、模型和日期筛选，查看结果、下载和详情，暂不允许用户删除任务记录。管理功能通过管理员专属入口访问。
- 前端采用 Vue 3、Element Plus、Vue Router、Pinia、Axios，图标使用 Element Plus 图标库。
- 后端使用 Python，其余技术组件及选型状态见[技术栈](tech-stack.md)。

### 公开模型、价格与 API 文档

- 访客可查看已上架模型及其本站唯一模型 ID、图片或视频类型、支持能力和公开售价。
- 价格与后台配置使用同一份数据库数据，不手工维护另一份公开价目。
- 图片标明每张价格；视频标明按次或按秒，以及各分辨率对应价格或共用价格。
- 积分价格按四位小数展示，页面不显示“1 元 = 1 积分”兑换提示。
- 首期公开目录仅展示已上架且配置完整的模型；模型下架后不再作为可用模型展示。
- 公开内容不包含供应商账号、接口凭证、采购成本、上游内部模型映射或用户数据。
- API 文档公开提供接入地址、鉴权方式、模型选择、接口参数、请求响应示例、错误处理、任务查询及计费说明。
- 文档明确图片一次只生成一张、视频的模型能力与价格差异、超时后仍继续查询等本站规则。
- 只公开已支持的开发者接口，兼容范围与本站扩展分别说明；具体接口清单仍需接入验证。
- 开发者 API 文档以已实现的 OpenAI 兼容接口为主，并标注实际开放状态；需要公开的本站扩展须单独说明。`/api/public/models` 仅供网站模型及价格页面使用，不作为开发者接入示例，不能替代 `/v1/models`；未实现的兼容接口不得展示为可调用。
- 公开阅读不等于匿名调用：生成、素材上传、任务查询、下载及账户操作仍按各自鉴权和归属规则执行。
- API 示例使用占位凭证，不公开真实 Key、任务信息或素材。

在现有 Vue 工程中提供官网首页、模型广场、API 文档、联系客服及注册登录入口，不另建文档网站或内容管理系统。模型能力与价格从数据库读取，通用接口说明与示例随实现维护。

### 界面与权限

- 官网、用户与管理页面放在同一前端工程中，共用登录与主题；官网使用顶部导航，控制台使用独立侧栏布局。
- 控制台各页面不显示页脚；各页面不显示积分兑换比例提示，积分兑换规则不变。
- 官网导航为首页、模型广场、API 文档；客服与主题集中放在右侧。未登录显示带小图标的注册和登录，已登录显示账号名，点击账号名进入控制台。
- 官网和控制台共用客服 Popover 展示二维码，当前先放占位；控制台右侧提供客服、公告铃铛与主题，公告仅在登录后的控制台显示，官网不显示公告入口。公告点击打开弹窗，使用时间线展示内容，当前暂无公告。公告数据和后台配置尚未接入。
- 用户控制台主菜单仅包含仪表盘、模型定价、API 令牌、任务日志、账户设置；不增加创作台。
- 登录后仍可浏览官网，不自动将公开页面跳转至控制台。
- 本轮先拆分布局，需要图片和视频的位置使用占位，后续逐步确定视觉和素材。
- 根据当前账号权限展示菜单和控制路由访问。
- 未登录访客可以访问首页、模型广场、API 文档、注册和登录页面，以及客服 Popover；登录守卫不得拦截公开内容。
- 管理员拥有普通用户全部功能，并额外拥有管理功能。
- 管理员可在用户管理的操作菜单中增加或扣除用户可用积分，必须填写金额和备注，变更写入账务流水。
- 普通业务页面中的个人数据仍按当前账号展示，全站数据通过管理功能访问。
- 后端独立校验管理员权限和用户数据归属，不能仅依赖前端菜单隐藏。

### 主题模式

- 全站提供明亮、暗黑、跟随系统三种模式，用户页面和管理页面统一生效。
- 明亮或暗黑为手动选择，系统配色变化时不覆盖用户选择。
- 跟随系统模式下，系统切换配色时页面自动更新，无须刷新。
- 登录、注册、导航、表格、表单、弹窗、下拉菜单和提示信息均适配两种实际配色。
- 统一使用 Element Plus 主题变量和项目语义颜色变量，保证文字、边框和状态反馈可辨认。

第一版实施默认：首次访问使用跟随系统；主题选择保存在当前浏览器，刷新后恢复。该项作为个人设备偏好，不新增数据库偏好表或跨设备同步功能；后续若需要账户同步再扩充。具体实现和界面验收见[UI/UX Pro Max 使用与界面规范](ui-ux-pro-max.md)。

### 模型与供应商

每个对外模型分别保存：

| 字段 | 含义 |
| --- | --- |
| 本站唯一模型 ID | 用户调用 API 时填写的模型标识，全局唯一 |
| 供应商 | 本模型实际调用的上游站点及配置 |
| 上游模型 ID | 适配器提交给供应商的实际模型标识 |
| 计费方式 | 图片按张；视频按次（每条）或按秒 |
| 成本价 | 上游采购成本单价或价目，由管理员设置，仅管理端可见 |
| 售价 | 向用户收取的积分单价或价目，由管理员独立设置；视频可以按分辨率设置不同价格，也可以共用价格 |

- 一个对外模型只绑定一个供应商和一个上游模型 ID。
- 不设多线路实体，不做自动选路、自动切换或供应商价格比较。
- 同一上游模型由不同供应商提供时，需要分别创建不同的本站模型 ID。
- 上线模型由管理员在后台添加、修改、启停，不在代码中固定首批模型清单。
- 图片第一阶段只接沧元；其他供应商的视频接入按实际协议和模型能力落实。
- 当前图片接入目标为 `gpt-image-2`、`gpt-image-2.5`、`gpt-image-2.6` 三个系列。用户最新指定的三个章节页为当前主要资料，具体型号、档位与能力差异见[沧元图片当前接入基线](providers.md#沧元图片当前接入基线)；系列名不代替具体上游模型 ID，不将旧次实测视为新版验证。
- 本次不接基础 web 型号 `gpt-image-2.5`、`gpt-image-2.6`；2.5、2.6 的 web 按 flare、sunburst 分支命名，固定档位另加 `-1k`、`-2k`、`-4k`。未核验开放状态与价格的分支型号不得上架，也不能用基础型号替代。
- 本次选定二十个独立型号：2 系列为基础 web 与 1k、2k、4k 共四个；2.5、2.6 各为 flare、sunburst 的 web 与三个固定档位，共八个。不使用 `-x` 聚合。2026-11-08 已录入本地数据库并保持下架；2.6 的两个 web 记录按用户确认值配置成本 CNY 0.0150/张、售价 0.0150 积分/张，实际调用仍待核验。实际配置状态见[上游接入说明](providers.md#本次型号选择与报价核对2026-11-08)。
- 本次图片价目初始设置为成本与售价同额，分别保存，管理员后续可独立调整；质量值与计费档的核对结果见[上游接入说明](providers.md#本次型号选择与报价核对2026-11-08)。
- 管理员确认当前数据库的全部图片模型支持 mask，已批量启用 `supports_mask`；该能力由数据库和后台开关维护，不按代码中的型号预设阻止开启。实际蒙版请求编码与素材约束在接入时核验。
- 已有协议支持的模型可通过配置增加；全新协议需要开发对应适配代码。
- 管理员调整模型绑定后，已有任务仍须保留原供应商和上游任务关联。
- API Key 页面展示名称、密钥、状态、创建时间、过期时间和操作；密钥支持查看和复制，操作支持编辑和删除。
- 视频使用统一的常用参数集合，按各模型实际能力决定可用参数、默认值和可选值，不建设任意特有参数的配置引擎。
- 暂不设置本站用户、API Key 或供应商的业务调用次数、频率、并发配额；上游能力约束、鉴权和输入校验仍需保留。

### 用户与充值

- 开放用户注册，使用邮箱和密码。
- 暂不验证邮箱，暂不提供找回密码，不为这两个功能接入邮件服务。
- 1 元人民币对应 1 积分。
- 积分余额、单价及账务金额使用四位小数，金额计算结果按普通四舍五入保留四位小数，不使用银行家舍入。
- 首期通过后台生成指定积分额度的兑换码，用户兑换后增加积分。
- 兑换码单次使用，不设置有效期，不提供禁用功能；兑换到账必须防止重复执行。
- 首期不接在线支付。
- 提交任务时冻结积分，成功后结算，明确失败后释放冻结积分或退回已扣积分；同一笔金额不得重复释放或退款。
- 生成结果完成转存至本站 OSS 后，才认定成功并结算；仅上游生成成功不满足结算条件。
- 转存未完成时不交付为成功、不结算；不能仅因请求超时就结算或退款。

### 图片与视频计价

- 图片、视频均分别记录成本价和售价，管理员在后台维护，业务配置保存到数据库。
- 成本价与售价独立，不按固定利润率自动推导，不用供应商公开报价自动覆盖管理员配置。
- 不同参数组合是否同价由后台配置决定，不在代码中固定所有档位或质量必须同价；图片的实际计价参数与模型支持能力对齐。
- 成本价仅管理端可见，公开模型页、用户页面和开发者响应只提供应公开的售价，不暴露采购成本。
- 任务保存创建时匹配的成本价与售价快照，后续调价不追溯修改已有任务。
- 管理员配置的成本用于记录和估算，不等同于已核验的上游实际扣费；实际扣费尚未获取时，不标记为已核对，也不默认记为零。
- 图片按张计价，一次请求只生成一张。
- 图片数量省略时按一张处理；显式请求其他数量时拒绝，不拆成多次上游调用。
- 视频按次（每条）或按秒计价，由管理员在后台配置。
- 每个模型配置支持的分辨率和价目，可以让不同分辨率分别定价，也可以让多种分辨率共用一个价格。
- 后台支持例如 720p、1080p 分别定价，也支持 480p、720p、1080p 使用相同价格；这些只是能力示例，不是固定模型清单。
- 计价规则限定在实际需要的模型、分辨率、计费单位和单价，不增加通用公式或规则引擎。
- 视频按秒计费时，按用户提交参数中指定并通过模型能力校验的秒数计费，不按结果实际时长重新计算，也不另行取整计费秒数。
- 提交冻结与成功结算均使用该请求时长和创建任务时的价目快照；金额为单价乘以指定秒数，再四舍五入到四位小数。

### 素材

- 同时支持本站上传、外部 URL。
- 本站对象存储确定使用阿里云 OSS，用于本站上传素材和全部生成结果。
- 图片、视频生成结果统一转存至本站 OSS，转存完成后再交付并结算；不直接使用供应商临时地址作为最终交付结果。
- 本站素材暂时都保留，不实施 24 小时自动过期、失效或删除。
- 不因取消创作台而取消 API 素材上传能力。
- 本站只管理本站持有的文件，不控制外部 URL 原文件的保留时间。
- 文件大小、格式、阿里云 OSS 连接及业务配置尽量通过后台管理；敏感凭证加密保存、脱敏展示，不记录到日志或公开响应。
- 按上游接入方式处理素材：需要 Base64 时由本站转换；支持 HTTPS 素材地址时直接传递符合要求的地址。
- 不强制把可直接使用的外部 HTTPS 素材再转存一遍；上游需要素材入库等特殊流程时由对应适配器处理。

### 任务与异常

- 本站维护内部任务编号及上游任务编号。
- 超时任务显示为超时，后台继续查询原上游任务，不因为展示超时而终止查询。
- 不把超时直接等同于供应商生成失败。
- 对无法通过后台查询确认的情况，仍保留管理员核实处理入口。
- 超时后收到上游成功结果，自动转存至本站 OSS；转存完成后自动交付并结算，无须管理员逐笔确认。
- 转存失败时保留恢复所需记录，不视为交付成功、不结算；仅恢复转存，不重新生成。
- 查询始终无法得到终态时如何停止查询仍待确认，不能自行按失败释放积分。
- 查询或转存失败不能直接触发再次生成；提交是否受理不明时先核实，避免重复生成和扣费。

### 记录保留

- 素材、任务、生成结果及相关业务记录暂时都保留。
- 本站暂不增加自动到期删除、定时清理或历史归档模块。
- 日志、积分流水和审计记录也暂不设置业务自动清理策略。
- 保留策略不代表外部素材或供应商下载地址永久有效，也不允许日志记录凭证、密码或完整媒体内容。

### 配置

- 模型、供应商、价格、任务参数及常规业务设置尽量存数据库。
- 管理后台提供对应的编辑和校验功能。
- 数据库连接、凭证加密主密钥等启动所需配置由部署环境提供。
- 协议流程由代码实现，不建设可编排任意协议的配置引擎。

官网与控制台采用不同布局，共用同一 Vue 工程、登录与三态主题。图标使用 Element Plus 图标库。

| 区域 | 页面 |
